08 Dashboard Status Contract

公開投影｜來源、狀態與發布邊界

English查看空白範本查看填寫示例
Order Book 合成教學情境，非真實交易所實測。沿用本站 Fail Demo 的序號覆寫案例；價格、數量與時間是教學補充設定。Run、缺陷及證據名稱均為合成示例，沒有真實產品操作、證據附件或客戶核准。

這份文件回答什麼

08 Dashboard Status Contract 規定如何把已核准的 07 Release Quality Summary 投影成公開狀態。Run 保存執行，07 保存判斷，08 定義可公開的欄位及驗證方式。

空白範本

〔必填〕每案都要有；〔條件式〕適用時必填，不適用寫原因。複製下方文字到案件文件後替換方括號內容。本頁為靜態範本，沒有編輯或儲存功能。

〔必填〕Assessment source／版本、contractVersion、schema、exporter／policy／publisher workflow 版本與 SHA：[ ]
〔必填〕公開 subject：repository／release／branch／fullSha；objective、environment、testedScope、excludedScope：[ ]
〔必填〕核准的 releaseAssessment：status／rationale／decidedAt／expiresAt／qaOwner／reviewer／decisionOwner：[ ]
〔必填〕summary：effortLevel／coverage／quality／comment：[ ]
〔必填〕productAreas：id／name／effortLevel／executionState／coverage／targetCoverage／quality／comment／evidenceLinks：[ ]
〔必填〕gates：id／title／note／state；runs：runId／executedAt／evidenceUrl：[ ]
〔必填〕provenance：generatedAt／syncedAt／sourceSha；dataStatus／publicDisclosure：[ ]
〔必填〕檢查：subject 相符、來源授權、schema／版本、時效、阻斷／waiver、allowlist／連結、秘密／PII、atomic manifest／last-known-good：[ ]
〔必填〕公開覆核人／結果／時間、允許與禁止欄位：[ ]
〔必填〕發布與修正：產生／同步時間、manifest／hash、last-known-good、修正／撤回程序、rollback owner、發布後 smoke 證據：[ ]
由核准的 07 產生唯讀投影，不另填第二份決策；無核准不輸出可發布 snapshot。

填寫示例：Blocked 的投影規劃

欄位合成示例
來源／版本DEMO-QUALITY-MDQ v1.2；contractVersion 1.0.0；schema/test-status.schema.json；current policy 2.1.0。exporter／publisher SHA 待填，沒有核准來源。
Subject／範圍DEMO-BOOK／build-demo-1；真實 repository／branch／fullSha Unknown。三案與未測範圍引用 07；不填假的 full SHA，不產出可發布 JSON。
產品狀態／理由教學推導 Blocked：DEF-MDQ-004 是未解決 S1，且 TC-MDQ-017 有合成 Fail。QA／reviewer／decision owner、decidedAt／expiresAt 尚未核准；不是正式 release assessment。
資料狀態正式 snapshot 尚未設定，閱讀標籤 Not Configured。沒有真實同步或時效證據，不能把教材日期當 Fresh。
Summary／Product Area教學區域 Order Book：quality=bad，executionState=complete（合成三案已完成）；coverage／effort 未核定，不由 100% 完成率推定。comment 指向合成 S1；正式 evidenceLinks 待核准。
Gates／Runs／provenanceG3／G6 未有正式證據或核准；教材 Run 引用 DEMO-RUN-FAIL-001，不得冒充真實執行。generatedAt／syncedAt／sourceSha 未產生。
公開檢查／發布只含合成 ID、教學假設及角色；真實 schema／subject／時效／授權驗證尚未執行。publicDisclosure、公開 reviewer／時間、manifest／hash、last-known-good、rollback owner 與 smoke 證據皆待實案提供；本頁沒有發布。

產品狀態與資料狀態分開

狀態判定
Blocked可信且同版本的未解決 S1、未接受 S2 或關鍵路徑不符合；證據過期仍保留已知問題，另列資料不足。
At Risk沒有阻斷問題，但仍有剩餘缺陷或已接受風險；記責任與後續，不等於准許發布。
Unknown沒有可信的已知阻斷或剩餘問題，但判準、證據或覆核不足；損毀／subject 不符資料不能建立產品事實。
Ready四面向均支持測試交付、沒有已知剩餘缺陷／接受風險，且有 human-owned assessment；實際發布另需 Go。歷史 Ready 不代表目前核准。
Data StatusFresh／Stale／Invalid／Not Configured／Unreachable 說明來源可用性；不能直接推論產品好壞，也不是即時監控。

修正與恢復

來源改版先比對受影響案例，新增必要 Run 與覆核；資料不合法時保留 last-known-good 並標失敗，不改寫舊 snapshot。修正、撤回、rollback 與發布後驗證由原責任流程處理；發送、發布或上線仍須授權。三種異常處理見 來源改版、覆核分歧與 AI 誤判。
