Order Book 合成教學情境，非真實交易所實測。沿用本站 Fail Demo 的序號覆寫案例；價格、數量與時間是教學補充設定。Run、缺陷及證據名稱均為合成示例，沒有真實產品操作、證據附件或客戶核准。

這份文件回答什麼

把已知問題、執行完整性、結束條件判定與未測部分分開交代。結果引用 Run Log；總結論由證據推導。

空白範本

〔必填〕每案都要有；〔條件式〕適用時必填，不適用寫原因。複製下方文字到案件文件後替換方括號內容。本頁為靜態範本，沒有編輯或儲存功能。

〔必填〕報告 ID／版本、本輪範圍、產品版本／環境、截止時間：[ ]
〔必填〕引用的 Spec／Case／Run／Defect／資料契約版本：[ ]
〔必填〕已知問題：[缺陷 ID、影響、未解決等級、處置與風險接受依據]
〔必填〕執行完整性：[選定範圍、實際完成、Blocked／Skipped／Not Run 及原因]
〔必填〕結束條件判定：[逐項條件、證據、未達項與有權人的決定]
〔必填〕未測部分：[案例、風險、原因與後續責任]
〔必填〕覆核與限制：[誰覆核什麼、依據、尚未完成項]
總結論由上述內容推導，不另獨立填寫；測試結束與批准上線分開。

DEMO-QUALITY-MDQ · v1.2

範圍：DEMO-SPEC-MDQ v1.2 的三個 Order Book 合成案例。截止時間為示意 2026-10-26 17:30 UTC+08:00；產品 build-demo-1，契約 DEMO-DC-MDQ v1.0。

面向本輪內容
已知問題DEF-MDQ-004：舊序號覆寫，S1 · Triaged · demo，未修復；無風險接受核准。
執行完整性選定 3 案，2 Pass、1 Fail；完成率 (2+1)/3 = 3/3 = 100%。Not Run／Blocked／Skipped 均為 0（合成）。完成率不是通過率。選定為 0 時應顯示 N/A。
結束條件判定條件 1：合成情境內三案必要步驟與檢查點已完成；真實當前證據未提供。條件 2：未達，仍有未解決 S1。條件 3：合成追溯鏈完整，無未解釋缺口。整輪不符合結束條件。
未測部分相同序號、跳號、亂序緩衝、零數量、缺值、壓力、真實 feed 與下單均未測。由產品／介接窗口確認規格，再按風險安排；不納入本輪三案分母。
覆核／限制所有結果是教學填寫；沒有真實產品執行、真人驗收或上線核准。文件 v1.2 沒有改變本站歷史 Run。
推導摘要（僅示例）：Blocked

雖然三案完成率 100%，仍有 1 筆未解決 S1。安排修正與新 Run 後再評估；本頁不填獨立的總結論欄位，也不表示真實產品的當前狀態。

Ready 僅表示約定測試交付條件達成；Go 仍需當前證據與有權人決定。修復宣稱及尚未發生的 rerun 都不能自動放行。
